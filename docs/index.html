01

The actual mechanic

$ juno = your words, executed

JUNO is a thin client. It reads your prompt, turns it into real actions, and runs them on your machine: launch apps, start timers, schedule reminders, read and list files - all surfaced as a keyboard-driven terminal app. With the AI on, every message is answered by chat.deepseek.com; with it off, a deterministic local engine handles the same commands with zero AI and zero accounts.

  • openlaunch any app by name - juno "open firefox".
  • closequit apps the same way you opened them.
  • timerset a timer for 30 minutes, or 90s, or 1h.
  • remindschedule a reminder - "remind me in 10 minutes to take a break".
  • readread and list files from the prompt, no retyping paths.
  • infosystem info on demand, as JSON when you want it.
02

Which AI's

bring your own brain, or none

JUNO rides on the DeepSeek account you're already logged into - or on nothing at all. Swap mid-session with /mode; it's one command, not a reinstall.

  • deepseek /mode deepseek

    the default. Connected through chat.deepseek.com - the account you likely already have. juno auth links it once.

  • off /mode off

    fully local. the deterministic engine answers opens, timers, math, file ops - no AI, no account, no browser.

04

Install

Free · Local-first

Clone and build it - juno lands on your PATH in about a minute.

linux · mac · windows
# clone, install, link the CLI:
git clone https://github.com/frteddz/JUNO.git
cd JUNO && npm install
cd packages/cli && npm link
juno auth
juno "open firefox"
  • needs:node ≥ 24, npm ≥ 11
  • no AI:juno config set aiProvider off
  • npm publish:on the roadmap - from source for now
