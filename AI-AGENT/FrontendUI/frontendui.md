# Frontend UI — Build Prompt

Goal: build polished, responsive UI components/screens. High visual quality, accessible, not template-y. Safe: no invented business data.

## 0 · INTAKE — ask before you build
**Batch A — UI (required)**
1. What are you building? (screens, component library, page sections)
2. Target (web/mobile), catalog for use
3. Framework/stack (React, Vue, plain HTML/CSS, etc.) or "you choose"
4. Design reference / vibe (minimal, bold, glassy, playful) — or describe a vibe
**Batch B — style system**
5. Palette (accent + background) or "you choose based on vibe"
6. Typography preference
7. Components needed and any existing style tokens
**Batch C — tech**
8. State/animation library preferences (Framer Motion, etc.)
9. Accessibility requirements (WCAG)
## Before you build
- Store tokens centrally; never invent live copy — use placeholder where needed.
- Echo a brief & confirm before writing.
